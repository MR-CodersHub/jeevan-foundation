# Jeevan Foundation Website

A responsive, four-page static website for presenting the foundation's mission, initiatives and community activity exhibition.

## Pages
- `index.html` — Home
- `about.html` — About Us (Story, Mission, Team)
- `service.html` — Our Initiatives (Seeds of Hope, Career Guidance, Broken Plates, Birthday Celebrations)
- `blog.html` — Our Impact (Editorial Stories & Filterable Photo Exhibition)
- `contact.html` — Contact & Volunteer Portal (Formspree Integration, Avadi Office Location)

## Run locally
No build step or package installation is required. Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
1. Replace the illustrative stock photos with authentic Jeevan Foundation activity photos.
2. Confirm all initiative descriptions, contact details and any published impact statements.
3. Add photo captions with event date, location and a short factual description.
4. Obtain consent before publishing identifiable photographs, especially children or people receiving food support.
5. Confirm the foundation's legal name and any registration details before adding them.
6. Test all pages on mobile and desktop.

## Notes
- No login, signup, donation, payment, fundraising or user-data collection features are included.
- Contact uses phone, email and an external map search link.
- Google Fonts and Unsplash images require an internet connection.
- The gallery contains clearly labelled illustrative stock images and is not evidence of completed foundation activities.
